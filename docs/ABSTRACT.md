# Student Record and Academic Management System - Abstract

The Student Record and Academic Management System (SRAMS) is a Python-based web application
that simplifies and automates academic administration in educational institutions. It provides
a centralised platform for managing student information, course details, attendance records,
examination marks, academic performance and reports.

The application is developed with Python and Streamlit, using SQLite as the database. It
provides role-based authentication for administrators, faculty members and students so that
each user can access only the information and functions appropriate to their role.

The system includes student registration, course allocation, attendance tracking, automatic
grade calculation, academic analytics and downloadable PDF, Excel and CSV reports. It also
provides a machine-learning model (Random Forest) that flags students who may be academically
at risk, a recommendation engine and a privacy-scoped academic assistant chatbot.

The main objective is to reduce manual administrative work, improve data accuracy, simplify
academic monitoring and give students easy access to their own academic information.

**Technologies used:** Python, Streamlit, SQLite, Pandas, NumPy, Plotly, scikit-learn,
bcrypt, ReportLab, OpenPyXL.
